# محراب و نور ـ بستهٔ آماده‌سازی GitHub Pages

این بستهٔ عمومیِ فشرده‌شده برای میزبانی ایستا آماده شده است. محتوای آموزشی، JSONهای مرجع، صوت‌ها و تصاویر موردنیاز در مسیرهای اصلی خود قرار دارند.

برای آزمایش محلی، از ریشهٔ بسته یک سرور HTTP اجرا کنید؛ برای نمونه:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000/` را باز کنید. فایل HTML را مستقیماً با `file://` اجرا نکنید.

هش SHA-256 فایل‌های بسته در `BUILD-MANIFEST.json` ثبت شده است. این بسته هنوز در GitHub منتشر نشده است و پیش از انتشار باید مجوز منابع و تنظیمات مخزن بررسی شوند.

حقوق اجزای اختصاصی پروژه مطابق `LICENSE` و `COPYRIGHT.md` است. منابع قرآنی، کتاب درسی، صوت‌ها و فونت‌ها تابع حقوق و مجوزهای صاحبان اصلی خود هستند.
